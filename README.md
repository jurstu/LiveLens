# LiveLens


## What this project is

A module, that implements a simple 3d rendering using abstracted 3d engine (pyrender for now). It allows to simply put.. change the camera intrinsics, extrinsics, the 3d world around You. 


## What is available

Setting roll, pitch, yaw, x, y, z, camera matrix, 3d objects in the world

## What is missing

- [ ] World generation based on WGS84 
- [ ] convertions of WGS84 to ENU/AR world 
- [ ] drawing 3d pictures 
- [ ] compass overlay
